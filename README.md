# Encryption & Decryption Tool (加解密工具)

A simple Python GUI tool for encrypting and decrypting text, built with Tkinter.

一个使用 Tkinter 构建的简单 Python 图形界面加解密工具。

## Features (功能)

- **Base64 Tool**: Simple encoding and decoding for daily use.
- **AES Tool**: Requires a secret key for encryption and decryption (using PyCryptodome library).
- **GUI Interface**: Built with Tkinter for user-friendly interaction.

## Requirements (环境依赖)

You need to install `pycryptodome` for the AES functionality:
```bash
pip install pycryptodome
